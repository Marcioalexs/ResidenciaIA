## Guiding Constraints consolidadas no documento v0.9

- Pelo menos um algoritmo de classificação.
- Pelo menos uma técnica de aprendizado supervisionado.
- Pelo menos uma técnica de aprendizado não supervisionado.
- Pelo menos uma metodologia de limpeza de dados.
- Pelo menos uma avaliação de métrica.
- O modelo deve ser escrito em Python.
- Pelo menos 3 técnicas de visualização de dados.
- A solução deve promover pensamento crítico.
- A solução deve considerar aspectos éticos do uso de IA.
- Protótipo funcional, campanha ou produto educacional.
- Atender a uma comunidade real.
- Validar com usuários reais.
- Apresentar evidências de impacto.
